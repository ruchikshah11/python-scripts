# Hollow Pyramid

Prints a hollow pyramid outline of stars (edges only, solid base), sized by `--rows`.

## Run it
```
python hollow_pyramid.py
python hollow_pyramid.py --rows 7
```

## Output (--rows 5, default)
```
    *
   * *
  *   *
 *     *
*********
```
