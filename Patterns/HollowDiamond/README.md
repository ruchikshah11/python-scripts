# Hollow Diamond Pattern

Prints a hollow diamond outline of stars (edges only, blank interior), sized by
`--rows` (half-height).

## Run it
```
python hollow_diamond.py
python hollow_diamond.py --rows 7
```

## Output (--rows 5, default)
```
    *
   * *
  *   *
 *     *
*       *
 *     *
  *   *
   * *
    *
```
