# Butterfly Pattern

Prints a butterfly pattern (two triangles mirrored side by side, widening then
narrowing), sized by `--rows` (half-height).

## Run it
```
python butterfly_pattern.py
python butterfly_pattern.py --rows 7
```

## Output (--rows 5, default)
```
*        *
**      **
***    ***
****  ****
**********
**********
****  ****
***    ***
**      **
*        *
```
