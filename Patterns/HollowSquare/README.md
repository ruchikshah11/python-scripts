# Hollow Square Pattern

Prints a hollow square outline of stars (border only, blank interior), sized by
`--rows`.

## Run it
```
python hollow_square.py
python hollow_square.py --rows 7
```

## Output (--rows 5, default)
```
*****
*   *
*   *
*   *
*****
```
