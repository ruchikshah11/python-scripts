# Alphabet Triangle

Prints an alphabet triangle — row *i* contains letters A through the i-th letter
concatenated (A / AB / ABC / ...), sized by `--rows`.

## Run it
```
python alphabet_triangle.py
python alphabet_triangle.py --rows 7
```

## Output (--rows 5, default)
```
A
AB
ABC
ABCD
ABCDE
```
