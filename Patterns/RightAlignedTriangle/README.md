# Right-Aligned Triangle Pattern

Prints a right-aligned right triangle of stars (1 star growing to `--rows` stars,
aligned to the right edge).

## Run it
```
python right_aligned_triangle.py
python right_aligned_triangle.py --rows 7
```

## Output (--rows 5, default)
```
    *
   **
  ***
 ****
*****
```
