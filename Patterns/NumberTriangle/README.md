# Number Triangle

Prints a number triangle — row *i* contains the digits 1 through *i* concatenated
(1 / 12 / 123 / ...), sized by `--rows`.

## Run it
```
python number_triangle.py
python number_triangle.py --rows 7
```

## Output (--rows 5, default)
```
1
12
123
1234
12345
```
