# Plus Pattern

Prints a plus/cross (+) sign made of stars in a `(2*rows-1) x (2*rows-1)` grid,
sized by `--rows` (half-width from the center).

## Run it
```
python plus_pattern.py
python plus_pattern.py --rows 7
```

## Output (--rows 5, default)
```
    *    
    *    
    *    
    *    
*********
    *    
    *    
    *    
    *    
```
