# Hourglass Pattern

Prints an hourglass of stars — a solid inverted pyramid on top of a solid pyramid
(the opposite of [Diamond](../Diamond/README.md)), sized by `--rows` (half-height).

## Run it
```
python hourglass.py
python hourglass.py --rows 7
```

## Output (--rows 5, default)
```
*********
 *******
  *****
   ***
    *
   ***
  *****
 *******
*********
```
