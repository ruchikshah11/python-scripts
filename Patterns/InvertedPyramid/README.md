# Inverted Pyramid Pattern

Prints a solid, centered inverted pyramid of stars, sized by `--rows`.

## Run it
```
python inverted_pyramid.py
python inverted_pyramid.py --rows 7
```

## Output (--rows 5, default)
```
*********
 *******
  *****
   ***
    *
```
