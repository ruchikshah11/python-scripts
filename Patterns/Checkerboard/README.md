# Checkerboard Pattern

Prints a checkerboard pattern of stars and spaces, sized by `--rows` (a
`--rows x --rows` grid).

## Run it
```
python checkerboard.py
python checkerboard.py --rows 8
```

## Output (--rows 5, default)
```
* * *
 * * 
* * *
 * * 
* * *
```
