# Palindromic Number Pattern

Prints a centered palindromic number pyramid (1 / 121 / 12321 / ...), sized by
`--rows`.

## Run it
```
python palindromic_pattern.py
python palindromic_pattern.py --rows 7
```

## Output (--rows 5, default)
```
    1    
   121   
  12321  
 1234321 
123454321
```
