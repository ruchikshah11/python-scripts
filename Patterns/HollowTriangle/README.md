# Hollow Triangle

Prints a hollow left-aligned right triangle outline of stars (edges only, solid
base), sized by `--rows`.

## Run it
```
python hollow_triangle.py
python hollow_triangle.py --rows 7
```

## Output (--rows 5, default)
```
*
**
* *
*  *
*****
```
