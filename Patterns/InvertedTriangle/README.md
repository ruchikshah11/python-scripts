# Inverted Triangle Pattern

Prints a left-aligned inverted right triangle of stars (`--rows` stars shrinking to 1).

## Run it
```
python inverted_triangle.py
python inverted_triangle.py --rows 7
```

## Output (--rows 5, default)
```
*****
****
***
**
*
```
