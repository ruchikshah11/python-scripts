# Number Pyramid

Prints a number pyramid — row *i* repeats the digit *i*, *i* times
(1 / 22 / 333 / ...), sized by `--rows`.

## Run it
```
python number_pyramid.py
python number_pyramid.py --rows 7
```

## Output (--rows 5, default)
```
1
22
333
4444
55555
```
