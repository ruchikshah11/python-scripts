# Pattern Visualizer

An interactive Tkinter viewer for every pattern in the [Patterns](../../Patterns/README.md)
folder — pick a pattern from the dropdown, drag the rows/size slider, and see it
update live. Reuses each pattern's actual `print_xxx()` function directly (via stdout
capture), rather than reimplementing any pattern's drawing logic here.

## Prerequisites
None beyond the standard library.

## Run it
```
python pattern_visualizer.py
```
- Pick a pattern from the dropdown
- Drag the slider to change `--rows`/`--size` (1–20)
- For **Character (any letter/digit)**, an extra field appears to type the character
  (reuses `CharacterPattern`'s font-rendering approach)

## How it works
`PATTERN_REGISTRY` maps each of the 25 loop-based patterns to its (folder, module,
function) — the folder is added to `sys.path`, the module imported, and its
`print_xxx(rows)` function called with `contextlib.redirect_stdout()` capturing the
output into the preview box. `CharacterPattern` is handled separately since its
`render_character_grid(char, size)` returns lines directly instead of printing them.

No pattern's logic is duplicated — every shape you see here is generated by the exact
same code as running that pattern's own script from the command line.

## Tested
**Headlessly verified all 26 patterns work correctly** by calling `load_pattern_modules()`
and running every registered function exactly as the GUI does — all 25 loop-based
patterns produced output with the expected line counts (e.g. Diamond/Hourglass/Plus/
Cross correctly produced 9 lines for the default size, matching their known shapes),
and `CharacterPattern` correctly rendered the letter R. This confirms the registry
mapping (folder/module/function names) has no typos and every reused function
actually runs — the layer most likely to break.

**Not verified**: the actual slider/dropdown interaction and visual layout — I have no
way to see or drag the widgets myself. Please open it and confirm the live-update
behavior feels right.
